# 内部点单工具（堂食 · 员工用）

> 目前是**内部使用**：员工用手机/平板打开，选桌号 → 点菜 → 发送到厨房 WhatsApp。
> 以后要给顾客自助点餐时，可以回滚到本仓库的 `a27237a`（顾客版）。

## 怎么用

1. 打开网址，输入员工密码（默认 `2468`，在 `js/config.js` 的 `internalPin` 改）；
2. 顶部选 **Mesa（桌号）**；
3. 点菜加入订单 → 打开购物车 → 可写厨房备注 → 发送到厨房 WhatsApp；
4. 点「＋ 新单」清空，接下一桌。

## 内容怎么改

| 内容 | 改哪里 | 影响 |
|---|---|---|
| 食品/价格/图片/上下架/店铺信息 | 旧店 `admin.html` | 堂食内部站 + 外卖站同步 |
| 汽水/酒水/果汁（堂食价） | `content/bebidas-local.json` | 只影响堂食站 |

## 说明

- 密码是**前端简易门禁**（防止误入），不是真正安全措施；页面已加 `noindex` 不被搜索引擎收录。
- 网址支持每桌二维码 `?mesa=5` 自动填桌号（内部用可忽略）。
- 改 JS/CSS 后把 `index.html`/`admin.html` 里的 `?v=` +1（当前 v=4）。
