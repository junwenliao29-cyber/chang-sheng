# 内部点单工具（堂食 · 员工用）

> 内部使用：员工用手机/平板打开 → 选桌号 → 点菜 → 发送到厨房 WhatsApp（已取消 PIN，打开即用）。

## 饮料的堂食价 / 外卖价怎么改

全部在 **后台管理** 里改，不需要改文件、也不需要改数据库：

1. 打开 `admin.html` → **🥤 饮料价格** 标签页；
2. 同一杯饮料有两列：**外卖价**（顾客外卖站用）和 **堂食价**（内部堂食站用）；
3. 堂食价留空 = 自动跟外卖价一样；改完自动保存、立刻生效。

## 堂食专属菜单（只显示在堂食链接）

在 **「🍜 菜单管理」** 页面顶部切换到 **🍽️ 堂食专属**，就能用和外卖**完全一样**的方式管理：

1. ＋ 新增分类 / ＋ 新增菜品（可写描述、传图片、拖动排序、↑↓、上下架）；
2. 回车=保存、上/下一道、快速查找 等快捷操作全部可用；
3. 保存后只出现在内部堂食站，**外卖站不显示**；切回「🍜 外卖菜单」就是原来的外卖菜单。
