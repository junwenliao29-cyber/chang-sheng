# 内部点单工具（堂食 · 员工用）

> 内部使用：员工用手机/平板打开 → 选桌号 → 点菜 → 发送到厨房 WhatsApp（已取消 PIN，打开即用）。

## 饮料的堂食价 / 外卖价怎么改

全部在 **后台管理** 里改，不需要改文件、也不需要改数据库：

1. 打开 `admin.html` → **🥤 饮料价格** 标签页；
2. 同一杯饮料有两列：**外卖价**（顾客外卖站用）和 **堂食价**（内部堂食站用）；
3. 堂食价留空 = 自动跟外卖价一样；改完自动保存、立刻生效。

## 堂食专属菜单（只显示在堂食链接）

在同一个「🥤 饮料价格」页面下方有 **🍽️ 堂食专属菜单**：

1. 「＋ 新增品类」建立只属于堂食的品类（例如果汁、酒水、堂食套餐）；
2. 「＋ 新增菜品 / 饮料」在该品类下加菜/饮料，填堂食价、图片、上下架；
3. 点「💾 保存堂食专属菜单」→ 只出现在内部堂食站，外卖站不会显示。
