🔧 第一步：连接数据库（只需一次）

管理后台需要连接 Supabase 云数据库才能保存你的修改。请按以下步骤操作：

  1. 打开 https://supabase.com，用邮箱免费注册并登录。
  2. 点击 New project 新建项目（免费 Free 套餐即可），记下项目密码。
  3. 项目建好后，打开左侧 SQL Editor，把本仓库 supabase/schema.sql 和 supabase/seed.sql 的内容依次粘贴进去，点 Run 执行（建表 + 写入示例菜单）。
  4. 打开左侧 Authentication → Users，点击 Add user，用你自己的邮箱和密码创建一个管理员账号。
  5. 打开左侧 Settings → API，复制 Project URL 和 anon public key。
  6. 编辑本仓库的 js/config.js，把两个值粘贴到 supabaseUrl 和 supabaseAnonKey，保存并重新发布到 GitHub Pages。

完成后刷新本页面，就会显示登录框。

📖 使用说明

  1. 改菜单：切到“菜单管理”，可以新增/删除分类和菜品、改西语名/中文名/价格/描述/图片、勾选“在售”来下架某道菜（顾客端显示 Agotado）。
  2. 改店铺信息：切到“店铺设置”，修改店名、WhatsApp 号码、地址、营业时间和顶部公告，点保存。
  3. 改完立刻生效：所有修改保存后，顾客刷新网站就能看到最新内容，无需重新发布代码。
  4. 菜品的图片：在“编辑菜品”里粘贴图片网址（https://…）即可显示照片；留空则显示中文占位字。
  5. 顾客下单：顾客加购 → 填姓名/地址 → 点按钮自动跳转你的 WhatsApp 并带上订单明细，你直接在 WhatsApp 回复确认即可。
  6. 换 WhatsApp 号码：只需在“店铺设置”里改号码，全站和下单跳转会自动更新。
  7. 传菜品图片：编辑菜品时点“🖼️”选择本地图片，或直接把图片/网页图片拖进去，也可粘贴图片网址；上传后自动保存到网站图库。
  8. 看访问统计：切到“访问统计”看每天/每时段多少人浏览、多少人下单及下单百分比。
